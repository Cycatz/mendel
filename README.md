# Mendel

Plants described as diploid genomes in [PODL](docs/podl.md), grown with L-systems and drawn as hand-coloured botanical plates.

![Sunray](docs/sunray.png)

Run `npm install`, then `npm run dev` and open the URL Vite prints. Keys 1–7 switch between starter plants (or use `?plant=N`), R regrows with a new seed, T toggles the roots, and the mouse orbits and zooms. `npm test` runs the tests.
